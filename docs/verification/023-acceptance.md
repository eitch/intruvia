## Failures and unrun checks

- Earlier tests exposed a missing viewer `ValueSet` (login 401), a subscription-test cleanup error, a log-rotation race, and DB emptiness/privilege gaps; fixes and regression tests were applied before the passing runs. A rehearsal initially failed because restrictive extraction removed template-directory access; the guide and archive test now preserve modes explicitly. A preliminary rehearsal was unnecessarily stopped by an incorrect interpretation that DB credentials could not be in Compose environments; the approved protected `.env` design was subsequently exercised.
- The first 023 snapshot manifest incorrectly repeated task 022's older hashes; all six checks failed against the current distribution. The manifest was corrected from measured artifacts and rechecked successfully. A prior progress message also incorrectly claimed a pre-implementation parser test had been run; no such run occurred.
- A preliminary attempt to use `/dev/null` for Maven's `-s`/`-gs` settings failed before dependency resolution because Maven requires a readable settings file; the release-resolution check succeeded with Maven's bundled neutral settings. The cached-coordinate hash mismatch described above was resolved by rebuilding with a fresh repository.
- The first `0.0.2` rehearsal attempt placed a full-table database-fingerprint comparison after duplicate ingestion and login and failed with `upgrade changed database state`; the exact request-side row difference was not isolated. The check was moved to immediately after candidate startup, before those requests; the final rehearsal exited 0, and API-level event/receipt, valid/revoked PAT, login and WSS checks passed independently. The final daemon security options contained no `name=rootless`, so rootless UID mapping was not exercised. Public DNS/CA issuance and power-loss behavior remain unrun; the successful local Caddy CA rehearsal is not evidence of public certificate issuance or crash durability. PostgreSQL emptiness checking is point-in-time: administrators must prevent other DB writers during bootstrap. The example database backup excludes ownership, ACLs and cluster-global roles/settings; restore of an older backup can lose later events/revocations, reuse sequence numbers and resurrect tokens.
